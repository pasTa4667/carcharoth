# Rule: Keep Documentation in Sync

After any architectural or feature change, you MUST adjust or add corresponding documentation:

- **Architectural changes**: Update `.claude/architecture.md` and any relevant files under `.claude/architecture/`.
- **New features**: Add or update the relevant documentation (e.g., feature-specific docs, `README.md`, or the appropriate `.claude/*.md` file).
- **Changed behavior**: Ensure existing docs no longer describe outdated behavior.

Documentation updates are part of the change itself — a change is not complete until the documentation reflects it.
